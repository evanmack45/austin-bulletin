Not fixed. Yesterday's run diagnosed it in `eleventy.config.js` — the `bulletins`
collection is sorted newest-first, but the RSS plugin re-sorts ascending before
applying `collection.limit: 10`, so the limit takes the ten oldest — and left it for

surprise decision. That reasoning still holds on an unattended run, so it is still
unfixed, and today is the second morning RSS subscribers do not receive the new
edition. It is a small fix and it is now costing something every day.
