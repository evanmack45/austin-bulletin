## Things worth the publisher's eye

- **The Anthropic item is single-sourced.** KXAN carried an Austin Business Journal
  report that Anthropic is in talks for a 2,842-acre gas-fired generation facility
  and data center development in Bastrop County, attributed to "several sources,"
  with no agreement finalized. EDITORIAL's accuracy rule 2 asks for two independent
  sources on a surprising claim and I have one. I ran it in Business & tech with
  the sourcing stated in the prose ("the Austin Business Journal reported, citing
  several sources… No agreement has been finalized") rather than asserting the
  lease, and flag it here. If you would rather single-sourced anonymous reports be
  dropped outright, say so and I will write that into EDITORIAL.
- **`npm run voices` X spend was not captured.** The command was piped through
  `tail -70`, which cut the header where the script prints posts billed and
  estimated spend. Worst case at the configured five queries × ten posts is about
  $0.25. The run itself worked and both Bluesky and X returned candidates. Next
  run should capture full stdout.
- **`npm run video` failed on the first clip.** FOX 7's "Family of woman killed are
  speaking out" returned HTTP 401 from YouTube's oEmbed endpoint on two attempts;
  CBS Austin clips fetched fine immediately after, so this looks like a
  per-video restriction, not an outage. The Francesca Ortiz item ran without video.
- **`npm run video` silently rewrites a shared data file, and it bit today.** The
  second clip I fetched, CBS Austin's flea market fire video, turned out to be
  **already embedded in the published 2026-08-23 bulletin**. Re-fetching it
  overwrote `src/_data/videos/yt-jQd7OggU5Wg.json` in place, repointing that
  edition's thumbnail from `/images/2026-08-23/…` to `/images/2026-08-25/…` — a
  silent change to a published edition. Caught at `git status` before committing;
  the file was reverted, the duplicate thumbnail deleted, and today's bulletin now
  uses a different, genuinely new CBS clip. **Two things for the publisher:** the
  script has no guard against re-fetching a video an earlier bulletin already uses,
  and any run that reaches for a clip an older edition ran will quietly rewrite
  that edition's image path. Worth a guard in `scripts/video.mjs` (refuse, or write
  a date-scoped id) — I have not changed the script, since tooling changes are
  yours to ask for.
- **A day-old Daily Texan story was dropped**: "City passes 2026-2027 operating
  budget, raises property taxes, utility rates." The council vote was Aug. 12,
  thirteen days ago, and the Bulletin has not covered it. It is not today's news,
  so it is not in today's River. Worth knowing that a $6.6 billion budget raising
  the typical homeowner's property taxes $113.76 and utility fees $172.08 a year
  passed before this site existed and has never appeared here.
- **This Weekend** was skipped, as EDITORIAL requires until a readable events
